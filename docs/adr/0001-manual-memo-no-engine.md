# 变位法典是纯手填备忘录，不内置法语变位引擎

**Status**: accepted

产品定位由用户直接定案：自己记录、类似备忘录、查看为主、自测为辅。因此法典不含任何变位规则或动词表——用户收录动词后，自己填写六行现在时的**词干**与**词尾**，法典原样保存，不校验、不补全、不推断**分组**。直接后果：**自测**只能"遮盖+点击揭晓"，无法判定对错；没有引擎就没有标准，判定只能拿用户的**记录值**去和另一套记录比较。

## Considered Options

- **引擎生成**：内置 -er/-ir 规则加不规则动词表，输入不定式即生成全套变位。否决：与"自己记录"的定位冲突，且要长期维护一张永远不全的法语不规则表。
- **引擎生成 + 逐格可覆盖**：否决：数据模型与输入 UI 复杂度最高，v1 不值当。

## Consequences

- 法典的正确性由用户承担：写错了它就错了。这是特性而非缺陷——手写本身就是学习动作。
- 将来若引入引擎，只能作为叠加在**记录值**之上的建议值，绝不能静默改写用户写下的内容。
- **分组**（1er / 2e / 3e）纯粹是列表筛选标签，不代表法典对变位规律的任何理解；代词 j' / je 的启发式（看该行文字首字母，**词干**为空时看**词尾**首字母）是排版便利，不是语法判断。

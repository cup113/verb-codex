# 名词辨性练习以内置词库为准

**Status**: accepted

产品需求要求一枚「名词阴阳性练习」入口：每局 20 题、有复习。这与 CONTEXT.md 的立身条款冲突——「法典不理解法语，只保管用户写下的内容」，Avoid 列表更直接排除词典、题库、学习 App，ADR 0001 也拒绝任何内置词表。决定：法典内置一份**词库**——由 Lexique 4.1 导出的、按词频排列的法语名词清单（词频前 1000，单一阴阳性、非复数、非 l' 省略，并剔除单字母与功能词），每个词附一条**中文短注**，**辨性**练习以它为唯一标准。词库是数据而不是引擎：它只回答「这个名词配 le 还是 la」，**中文短注**只帮认词；它不参与变位、不当词典、不写入任何**记录值**；ADR 0001 的边界因此收窄为「不内置动词变位表」，而非法语的完全无知。复习采用 4 箱 Leitner（立即 / 1 / 3 / 7 天，第 4 箱答对即**毕业**），**复习箱**落盘——这是「**默写**退出即焚」的第一处破例，破例只覆盖**复习箱**，**默写**本身仍不存任何东西。

## Considered Options

- **用户收录名词**（名词与阴阳性都是**记录值**，练习只拿**记录值**判）：否决——法典仍不懂法语，但要多一整套名词录入 UI，且与「先提供 demo」的节奏相悖；阴阳性练习的乐趣恰在于被考，而非背自己写下的纸。
- **只做错题池（不分区间）**：否决——没有间隔就不配叫复习；第二次打开时池子不会按遗忘节奏出现。
- **FSRS 调度**：否决——demo 与 v1 的共同负担过重；4 箱 Leitner 已能表达「错的常见、对的分级拉远」。
- **按动词数动态收窄词频下限**：否决——动词数是法语水平的弱代理，收窄行为不可见（用户不知道自己为何总撞见 top-200），demo 也无法演示。
- **内置整本词典（释义、音标、例句）**：否决——那是「不背法语」的产品，不是这本备忘录；法典只多知道一件事，且只为一件事。

## Consequences

- 法典第一次自带「它认识」的法语知识：**词库**。它只回答阴阳性，外加一条认词用的**中文短注**，别的什么都不知道。
- 词库来源 Lexique 4.1（CC BY-SA 4.0）：demo 页脚已署名；若随 App 发布，署名与同一许可的分发义务必须保留。
- **复习箱**是法典自己的账本，不是**主人**写下的**记录值**；它可被清空（demo 的 `Réinitialiser` 即先例），清空不损失任何记录。
- **中文短注**随词库分发，来源是批量标注（`tools/nouns-glosses.json`：每个名词一行、至多八字，覆盖率与长度由 `tools/make-nouns.py --glosses` 校核，抽样复核）；它是认词辅助，不是释义库，也不随用户变化。
- l' 省略名词（约 7,500 条）、双性别与复数名词不进词库：一道 le/la 题必须有无歧义的答案。
- 词库由 `tools/make-nouns.py` 从 Lexique 导出，demo 内联一份；将来 App 版由同一脚本生成数据模块，不手改词条。

# 默写以记录值为唯一比对标准

**Status**: accepted

产品需求要求默写能给出对错、并要求用户订正，这与 ADR 0001 的推论（没有引擎就没有标准，判定只能拿用户的**记录值**去和另一套记录比较）以及 CONTEXT.md 当时的禁令「禁止对/错反馈与计分」相冲突。决定：**默写**（la Dictée）作为与**自测**并列的模式，比对的唯一标准是该条目当前的**记录值**——`trim()` 后逐字一致，区分重音与大小写。法典依然不懂法语：它只判「是否与你亲手写下的一致」。旧禁令收窄为**自测**专属，**自测**仍只遮盖与揭晓。默写结果阅后即焚：不存分数、次数或历史。这是对 ADR 0001 推论的修订，不是推翻它的决定——法典仍不含任何变位引擎。

## Considered Options

- **折叠比对**（照查找的规格忽略大小写与重音）：否决——折叠是为「找到」服务的检索手段，默写要的是「默对」；重音正是法语变位的训练点。
- **内置引擎判定法语正误**：否决——ADR 0001 的决定不变。引擎若引入，只能作为叠加在**记录值**之上的建议值，绝不能成为第二套标准。
- **逐字符 diff，指出错在第几个字母**：否决——**整词**是原子；指出错在哪一段是被删除的「词干/词尾」两段式的还魂。

## Consequences

- 「全部正确」有了等级：首判全对盖 Sans faute 章，订正后全对盖次级的 Bien corrigé 章——奖励分层，才值得再默一次。
- 六行未填满的**动词条目**不能默写：对空**记录值**比对无意义，按钮置灰。
- 法典的正确性仍由**主人**承担：**记录值**本身写错，默写只会把错误练熟。这是用户自己法典的诚实，也是 ADR 0001 已经接受的代价。
